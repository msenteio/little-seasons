# Little Seasons

Play ideas for babies and toddlers, matched to age, season and today's weather. Activities draw on CDC milestones, AAP guidance and Montessori practice. Weather comes from [Open-Meteo](https://open-meteo.com/).

- `little-seasons.html` is the source (also published as a Claude artifact).
- `index.html` is the hosted page. Rebuild it after editing the source:

```bash
node build.mjs
```
